# Viewer UX: carousels, icon buttons, app icon and motion — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Carousel posts swipe through all their images and videos, the viewer's mute and Open on Instagram are icon buttons, the app has its own adaptive icon, and posts grow from and shrink back into their grid tile while pages use the shared-axis transition, both with predictive back.

**Architecture:**
- **Data.** `:instagram` parses `carousel_media` children into `RemoteCarouselItem`s. Room v2 adds a `carousel_item` table, which the sync fills in the post's own transaction.
- **Links.** A `PacedMediaInfo` helper, extracted from `RealVideoSourceResolver`, serves both video-link renewal and a new `CarouselRepository`. The repository fills missing items lazily and renews expired links, at most once per visit.
- **Viewer.** It nests a `HorizontalPager` per carousel post. Images are downloaded on demand through the existing cookieless CDN `MediaFetcher` into a `CarouselImageStore`; videos play through the existing player and cache.
- **Motion.** `SharedTransitionLayout` handles post↔tile; `NavHost` transitions give the shared axis between pages.

**Tech Stack:** Kotlin 2.4.20, AGP 9.4.1, Compose BOM 2026.09.00, Navigation Compose 2.10.2, Room (schema export on), Media3, Coil 3.6.3 (local files only), Robolectric 4.17, emulator tests on `emulator-5554`.

**Spec:** `docs/superpowers/specs/2026-10-12-viewer-ux-design.md`

## Global Constraints

- **Instagram code and pacing.** All Instagram-specific parsing stays in `:instagram`. Pacing is unchanged: sync sends no new request. A carousel's lazy fill or link renewal is one `mediaInfo` request on the Pacer's interactive lane, at most once per carousel visit, under the same session gates as video-link renewal (R76/R79).
- **Downloads.** Carousel images download on demand only, through the existing cookieless CDN `MediaFetcher` (`backend.fetcher`). They are never fetched with the session, and never during sync.
- **Database.** The migration from version 1 to 2 only adds `carousel_item`; every existing row stays. There is no destructive fallback.
- **Secrets and the public repo.** Never log or commit session material, raw Instagram responses, real handles, captions or CDN URLs. Fixtures are scrubbed (scrubbed fixtures use `cdninstagram.example`-style hosts and synthetic ids). The repo is public. Never use `--no-verify`.
- **Copy.**
  - Content descriptions and tooltips: "Mute", "Unmute", "Open on Instagram".
  - Item failure text: "Can't load this item".
  - Offline text for an unviewed item: "Offline: this item isn't cached yet".
  - Indicator: "N/M", 1-based.
- **Icons.** Glyphs are vector drawables from Material Symbols (Apache 2.0), not `material-icons-extended`. No Instagram logo.
- **App icon.** Adaptive: teal background `#0F6E56`, masonry-tiles foreground with a play triangle, a monochrome layer, all vectors.
- **Motion.** Shared element key `"media-<pk>"`. Pages use shared-axis X: forward slides in from the end with a fade, back reverses. `android:enableOnBackInvokedCallback="true"`. With the animator duration scale at 0, transitions are skipped.
- **Agents.** Agents never contact Instagram or log in, and never run anything against the owner's phone (serial 56191FDCR001TB). Emulator: `ANDROID_SERIAL=emulator-5554`, Mock mode, local data only.
- **Gradle env:** `export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home" ANDROID_HOME="$HOME/Library/Android/sdk";`

## Review Focus

1. A carousel whose items mix images and videos, where the owner swipes fast through them: exactly one video plays (the visible item's), audio never leaks from an off-screen item, and leaving the post stops it. Pinned in Task 4.
2. A carousel synced before this update (no stored items) opened offline or without a valid session: it shows the cover and "1/N", sends no request without a session, and never crashes. Pinned in Task 3.
3. An item whose CDN link has expired: one renewal per visit, then "Can't load this item"; never a request loop. Pinned in Task 3.
4. Going back after swiping to a post far below the opened one: the grid scrolls that tile into view and the post shrinks into it, with no jump to the top. Pinned in Task 6.
5. Delete library, or a Full sync that removes a carousel: its items and downloaded images go with it, and no orphan files or rows remain. Pinned in Tasks 2 and 3.

```kotlin
private fun carouselItem(c: JsonObject, i: Int, path: String): RemoteCarouselItem {
    val type = when (c.int("media_type")) {
        1 -> MediaType.IMAGE
        2 -> MediaType.VIDEO
        else -> throw ShapeChanged("$path.media_type")
    }
    val image = MediaLinks.chooseThumbnail(MediaLinks.imageCandidates(c))
    val videoUrl = if (type == MediaType.VIDEO) ((c["video_versions"] as? JsonArray)?.firstOrNull() as? JsonObject)?.string("url") else null
    return RemoteCarouselItem(
        position = i,
        type = type,
        width = c.int("original_width") ?: image?.width ?: 0,
        height = c.int("original_height") ?: image?.height ?: 0,
        imageUrl = image?.url.orEmpty(),
        videoUrl = videoUrl,
        videoUrlExpiresAt = videoUrl?.let(MediaLinks::expiresAt),
    )
}
```
